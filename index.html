Seiskasointujen tunnistusmenetelmä
  1. Lue kaikki neljä nuottia nimineen ja etumerkkeineen.
    Guitar adaptationissa älä päättele rootia pelkästä pystysuuntaisesta järjestyksestä.
  2. Järjestä nuottien kirjainnimet terssiketjuksi 1–3–5–7.
    Etsi järjestys, jossa kirjaimet etenevät joka toisen kirjaimen kautta. Esim. A, G♭, C, E♭ → A–C–E♭–G♭.
  3. Visuaalinen root-vihje inversioissa:
    Jos normaalissa nelisävelisessä seiskasointukuvassa kaksi vierekkäistä nuottia ovat sekunnin päässä toisistaan, sekunnin ylempi nuotti on yleensä root. Tämä kohta on terssiketjun 7 → 1 -liitos. Esim. F–A–C–D: C–D on sekunti, joten D on root.
  4. Terssiketjun ensimmäinen sävel on root.
    Etumerkit säilyvät mukana, mutta kirjainrunko kertoo sointusävelten funktiot.
  5. Laske muut sävelet aina rootista:
    root → terssi, root → kvintti, root → septimi.
  6. Muodosta puolisävelaskel-sormenjälki ja tunnista sointutyyppi.
0–4–7–11 = maj7
0–4–7–10 = 7
0–3–7–10 = m7
0–3–7–11 = m(maj7)
0–3–6–10 = m7♭5
0–3–6–9 = dim7
Tiivistettynä: lue nuotit → kokoa terssiketju → löydä root → laske 3/5/7 rootista → tunnista lukusarja.
